# MONO CHROME — QR Studio

[![Build Android APK](https://github.com/mohammedtaherahmmed-svg/My-apk/actions/workflows/Apk.yml/badge.svg)](https://github.com/mohammedtaherahmmed-svg/My-apk/actions/workflows/Apk.yml)

تطبيق كروت وQR كود لشركة **Mono Chrome for IVD Solutions**.

## تحميل الـ APK

1. افتح [Actions](https://github.com/mohammedtaherahmmed-svg/My-apk/actions/workflows/Apk.yml)
2. اضغط آخر تشغيل أخضر **Build Android APK**
3. من أسفل الصفحة حمّل **MonoChrome-QR**
4. فك الضغط وثبّت `app-debug.apk` على أندرويد (اسمح بالتثبيت من مصادر غير معروفة)

لو الشارة حمراء، البناء لسه فاشل. لو خضراء، الـ APK جاهز للتحميل.

## من الموبايل بعد التثبيت

- عدّل بيانات الشركة
- اختار نوع الـ QR (كارت اتصال / واتساب / هاتف / إيميل / موقع)
- احفظ الصورة أو شاركها
